methoddeterministic spread compression about a declared daily reference level
policyA spread compression pulls each market day's prices toward a declared daily reference level by a declared factor in [0, 1]. There is no default reference basis and no default factor: both are judgmental scenario inputs and must be stated. Compression preserves zero and negative prices as valid results and never clips them, so an interval's sign can change when it is pulled across the reference level; the count of such intervals is reported rather than suppressed. Spread widening (a factor above 1) is out of scope.
